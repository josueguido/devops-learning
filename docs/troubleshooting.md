## Guía de diagnóstico

1. Reproducí el síntoma y anotá el resultado esperado y el observado.
2. Identificá la capa afectada: cliente, frontend, API, base de datos o infraestructura.
3. Revisá conectividad, configuración y logs de una capa a la vez.
4. Cambiá una variable por intento y verificá si la hipótesis explica el resultado.
5. Documentá la causa raíz y una comprobación que permita detectar una regresión.

Los incidentes propios de una aplicación o despliegue deben registrarse también en el README del proyecto.
